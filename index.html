tydig

Typst, decentralized collaboration with iroh, saved in git.

A self-hosted collaborative Typst editor for papers written as pre-registered reports: the prose is fixed before the results exist, and every number and conclusion is computed by the project's own analysis.

Live preview and multi-cursor editing in the browser, comments pinned to the preview, sandboxed reproducible builds, post-quantum signed checkpoints, institutional sign-in, and every project kept as a plain git repository.

Run a hub

Needs only podman and just:

git clone https://github.com/cab-ucf/tydig && cd tydig
just

Open the printed address and create the first account. Share a project by email, then send the printed link: collaborators open it in any browser and start working, nothing to install, wherever your hub runs. To serve beyond your machine, see Production.
